# Relocation Website

Professional multilingual website for the European-to-Paraguay relocation and business establishment service.

## Tech Stack

- **Next.js 14** — React framework with App Router
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Utility-first styling
- **next-intl** — Internationalization (NL, EN, DE, ES)

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the site.

## Languages

- **Dutch (NL)** — Primary, default locale
- **English (EN)** — Secondary
- **German (DE)** — Tertiary
- **Spanish (ES)** — For local credibility

## Brand Guidelines

- **Colors:** Navy (#1B2A4A) + Gold (#C9A84C) + White
- **Fonts:** Playfair Display (headings) + Inter (body)
- **Tone:** Professional, trustworthy, clear
